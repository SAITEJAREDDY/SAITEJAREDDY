## How I approach the work


- **Start with the user and the decision.** Define the problem, the workflow, and what a useful outcome looks like before choosing the technology.
- **Use AI selectively.** Ground recommendations in relevant evidence and use explicit rules for calculations and policy checks.
- **Evaluate the trade-offs.** Examine quality, latency, cost, and failure modes, then use the findings to decide what to improve next.
